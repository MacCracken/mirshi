# P(-1) sweep — 2026-11-12 (1.12.3)

**Scope:** all of `src/` against the agnos kernel at `aef48206` (1.57.19), the cyrius 6.7.18 stdlib, and the
prior audit ([2026-06-30](2026-06-30-audit.md)).

**Method:** four parallel read-only reviews, each confirming its findings with fixtures built against a
scratch copy of mirshi:
1. hardening and input validation;
2. kernel fidelity for the fs / process / exec / memory / time calls;
3. kernel fidelity for the net / signal / I/O-mux / info / console calls;
4. supervisor robustness and the per-syscall hot path.

One further hardening item was found while reviewing the confined path code: the confined `*at` calls.

**Result:** about 45 findings.
- **Fixed in 1.12.3:** the hardening items, the robustness majors, and every contained fidelity item.
- **Filed on the [roadmap](../development/roadmap.md):** items that need a design decision (1.13.x–1.16.x)
  and the refactor leftovers.

## Fixed in 1.12.3

### Hardening (`--root`, `--net`, the child's environment)

| Area | Change |
|---|---|
| Confined path ops | `mkdir` / `rmdir` / `unlink` / `rename` / `link` / `stat` / `readlink` under `--root` now run in the supervisor, on a parent directory resolved with `openat2(RESOLVE_IN_ROOT)`. A symlink inside the rootfs that names an absolute host path now resolves inside the root. `..` clamps at the root, as on the kernel. A final `.` / `..` is refused. |
| Child fds | A child starts with fds 0–2 and its root anchor. Every other inherited fd is closed before exec (`close_range`). `close#6` refuses fd ≥ 32, so the anchor cannot be closed, and `dup#8` is the kernel's identity. |
| `execwait#37` / `spawn_path#43` | Under `--root`, the path is resolved inside the root (`openat2` + `execveat`). |
| Egress | 0.0.0.0/8, 100.64.0.0/10, 224.0.0.0/4 and 240.0.0.0/4 are reserved blocks that a broad allow (`0.0.0.0/0`) does not cover. |
| `sock_listen#56` | The argument is decoded as the kernel does (port, class bits). A loopback-class listener stays on 127.0.0.1 under `--net-listen-any`. |
| `udp_bind#51` | No `SO_REUSEADDR`; a port that is already bound is refused, as on the kernel. |
| Paths | A path with a NUL inside its length, or of length 0, is refused. |
| Seccomp allowlist | Seven entries no translation emits any more are removed. |
| `spawn#3` | The memfd is `MFD_CLOEXEC`. |

### Robustness

- A child's host sockets are closed and its slots freed when it dies. Its record slot keeps the tables for
  reuse rather than allocating new ones.
- Records no one can wait for any more (a dead parent's exited children) are freed.
- A failed `GETREGS` at an enter stop skips the stop, and the host-pid lookup ignores exited records.
- `sock_accept#57` finds a slot before it accepts.
- TCP and UDP receives peek, then take the data only after the child's buffers were written.
- The ENOSYS diagnostic is printed once per number.

### Fidelity (contained)

- **`spawn_path#43`:**
  - The `len | flags` argument (`SPAWN_F_ARGV`, `SPAWN_F_CLEANFD`) is decoded.
  - The argv blob is validated.
  - The kernel's `-2` / `-6` answers are returned, and more than 16 tokens is refused.
- **`close#6`:** a free fd < 32 closes to 0, and a closed signalfd closes to 0.
- **`open#7`:** `AO_MODE` sets the create mode; a mode above 07777 is refused.
- **`getdents#29`:**
  - Records are padded to 8.
  - A buffer that holds no record is -1, and so is a negative size.
- **Lengths and counts:**
  - `mmap#27` / `munmap#28`: a length ≤ 0 is one 2 MB unit.
  - `sleep_ms#41`: a negative value is -1.
  - `lseek#58`: a whence outside 0..2 is -1.
  - `getrandom#45`: a length ≤ 0 is 0, and the flags are ignored.
- **Ports and UDP:**
  - `sock_connect#47` and `udp_bind#51` take ports 1..65535.
  - `udp_send#52` answers the frame length (payload + 42), refuses more than 1472 bytes, and answers 0
    for len ≤ 0 first.
  - `udp_recv#53` answers 0 for maxlen ≤ 0 first.
- **Others:**
  - `net_config#61`: fields 4..11 (the kernel's counters) are 0.
  - `kill#16`: signal 0 is a probe that answers 0.
  - `epoll_ctl#20`: an unknown op is 0, and op 3 is -1 until it is implemented.
  - `epoll_wait#21`: the kernel's argument checks.

### Optimization and refactor

- **Emulated calls** get their answer in the enter-stop register write, which saves two ptrace calls per
  emulated syscall (`getpid` 25.4 → 24.1 µs).
- **`src/dispatch.cyr`** (2,585 lines) is split, as a pure move in the same order, into:
  - `src/emu_core.cyr`;
  - eight `src/band_*.cyr` files (fs, net, signals, iomux, info, kbscan, fdkind, console);
  - `translate_dispatch` itself, which stays in `src/dispatch.cyr`.
- **28 constants** that the stdlib defines with the same value were removed from `src/`.

## Upstream draft (agnos)

`sigprocmask#17` writes `oldset` before it reads `set` (`kernel/core/syscall.cyr`, the `num == 17` arm), so with
`set == oldset` the call applies the old mask. For `how` 1 (UNBLOCK) that unblocks every signal. The fix is to read
`set` first, as Linux's `rt_sigprocmask` does. mirshi already reads `set` first (ADR 0014, *Amendment*).
